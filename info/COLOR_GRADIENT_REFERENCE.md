## CSS Gradient Syntax Cheat Sheet

### Red → Yellow Gradient
```css
/* Cards */
background: linear-gradient(135deg, 
    rgba(255, 76, 76, 0.1), 
    rgba(255, 235, 59, 0.1)
);

/* Hover state (darker) */
background: linear-gradient(135deg, 
    rgba(255, 76, 76, 0.15), 
    rgba(255, 235, 59, 0.15)
);

/* Icon solid gradient */
background: linear-gradient(135deg, 
    #ff4c4c, 
    #ff6666
);
```

### Purple → Pink Gradient
```css
/* Section background */
background: linear-gradient(135deg, 
    rgba(128, 0, 192, 0.08), 
    rgba(255, 64, 128, 0.08)
);

/* Item cards (lighter) */
background: linear-gradient(135deg, 
    rgba(200, 128, 224, 0.08), 
    rgba(255, 128, 176, 0.08)
);

/* Bullet solid gradient */
background: linear-gradient(135deg, 
    #8000c0, 
    #ff4080
);

/* Hover state (darker) */
background: linear-gradient(135deg, 
    rgba(200, 128, 224, 0.12), 
    rgba(255, 128, 176, 0.12)
);
```

### Blue → Green Gradient
```css
/* Section background */
background: linear-gradient(135deg, 
    rgba(30, 144, 255, 0.12), 
    rgba(40, 167, 69, 0.12)
);

/* Icon solid gradient */
background: linear-gradient(135deg, 
    #1e90ff, 
    #28a745
);
```

### Rainbow Body Background
```css
background: linear-gradient(
    135deg,
    rgba(255, 245, 245, 0.75) 0%,      /* Soft red */
    rgba(255, 252, 240, 0.75) 16.67%,  /* Soft yellow */
    rgba(245, 255, 245, 0.75) 33.33%,  /* Soft green */
    rgba(240, 250, 255, 0.75) 50%,     /* Soft blue */
    rgba(250, 245, 255, 0.75) 66.67%,  /* Soft purple */
    rgba(255, 245, 250, 0.75) 100%     /* Soft pink */
);
```

## Color Psychology & Meaning

| Color | Psychology | Usage |
|-------|-----------|-------|
| **Red** | Attention, warning, importance | Limitations (things to watch) |
| **Yellow** | Optimism, caution, energy | Balance with red |
| **Blue** | Trust, credibility, data | Statistics (scientific rigor) |
| **Green** | Growth, wellness, validation | Complement blue (confirmation) |
| **Purple** | Wisdom, nuance, complexity | Considerations (think carefully) |
| **Pink** | Thoughtfulness, care, balance | Complement purple (empathy) |

---

## Opacity Strategy

All gradients use **subtle opacity** (0.08–0.15) rather than solid colors:
- ✅ Allows body gradient to show through
- ✅ Creates layered depth
- ✅ Maintains readability of text
- ✅ Feels modern and sophisticated
- ✅ Reduces visual fatigue on long read

## Animation with Color

```css
/* Cards start invisible, then animate up */
.limitation-card {
    opacity: 0;
    animation: slideUpCard 0.7s ease-out forwards;
}

/* On hover, colors brighten */
.limitation-card:hover {
    background: linear-gradient(135deg, 
        rgba(255, 76, 76, 0.15),    /* Darker red */
        rgba(255, 235, 59, 0.15)    /* Darker yellow */
    );
    box-shadow: 0 12px 35px rgba(255, 76, 76, 0.2);
}
```

The color shift on hover provides visual feedback that an element is interactive.
